## 三、以旧换新

### 估价参考（旧电视回收价）

| 旧电视尺寸 | 完好可开机 | 屏幕损坏/不开机 |
|---|---|---|
| 32-43寸 | 50-150元 | 20-50元 |
| 50-55寸 | 150-300元 | 50-100元 |
| 65寸 | 300-500元 | 100-200元 |
| 75寸及以上 | 500-1000元 | 200-400元 |

### 以旧换新补贴（国补+厂补+平台补）

| 新电视价格区间 | 补贴标准 |
|---|---|
| 3000元以下 | 按旧机评估价+额外补贴50-100元 |
| 3000-5000元 | 旧机评估价+额外补贴100-200元 |
| 5000-8000元 | 旧机评估价+额外补贴200-400元 |
| 8000元以上 | 旧机评估价+额外补贴400-800元 |

**以旧换新流程：**
1. 商品页点击"以旧换新"→选择旧机品类/品牌/尺寸/状态
2. 系统即时估价（估价7天内有效）
3. 下单时抵扣旧机款+补贴
4. 送新拖旧同步：新电视送达时同步回收旧电视
5. 旧机检测后如与描述不符，回收价多退少补

**注意：**
- 以旧换新补贴与满减二选一，系统自动选择最优方案
- 旧机需能出示购买凭证或身份证明
- 一台旧机只能换一台新机

## 四、国补政策（家电以旧换新国家补贴）

### 2026年家电国补标准（以当地政策为准）

| 品类 | 补贴标准 | 上限 |
|---|---|---|
| 电视（一级能效） | 售价×20% | 单台最高2000元 |
| 电视（二级能效） | 售价×15% | 单台最高1500元 |

**国补条件：**
1. 收货人身份需为补贴地区户籍/社保/居住证持有人
2. 每人每品类限享受1次补贴
3. 商品必须为一级或二级能效（三级及以下不享受）
4. 收货地址需在国补政策覆盖地区
5. 需实名认证，支付时自动核减

**注意：**
- 国补与满减可叠加，与以旧换新补贴可叠加（部分地区除外）
- 国补名额有限，先到先得
- 退货时国补金额需退回
- 具体补贴地区、比例、上限以结算页展示为准

## 五、价保规则

| 用户类型 | 价保期限 | 说明 |
|---|---|---|
| 普通用户 | 签收后7天 | 商品降价可申请退差价 |
| PLUS会员 | 签收后30天 | 部分商品延长至30天 |
| 大促期间 | 大促价保期 | 618/双11期间价保30天（以活动规则为准） |

**价保规则：**
1. 价保期内商品降价（同款同规格），可申请退差价
2. 差价 = 实付价 - 当前价（扣除优惠券后）
3. 订单详情页→"申请价保"→系统自动审核→差价原路退回
4. 以下情况不支持价保：秒杀/限量抢购、赠品变化、使用了不可叠加的券
5. 价保审核时效约1-3个工作日

## 六、优惠叠加规则

### 可叠加
- 满减 + PLUS专享价
- 满减 + 全品类券/家电券
- 满减 + 国补
- 国补 + 以旧换新补贴（大部分地区）
- PLUS券 + 国补

### 互斥（二选一，系统自动选最优）
- 满减 vs 以旧换新补贴（部分商品）
- 平台券 vs 店铺券（部分活动）
- 秒杀价 vs 满减

### 计算顺序
1. 商品标价
2. 满减/以旧换新（二选一，取优惠大的）
3. PLUS专享价/优惠券
4. 国补（按折后价×补贴比例）
5. = 最终到手价

**示例：**
- 电视标价7999元，满5000减600，PLUS券减300，国补20%（上限2000）
- 计算：7999 - 600 - 300 = 7099 → 7099×20% = 1419.8 → 到手价约5679元
- （具体以结算页为准）
