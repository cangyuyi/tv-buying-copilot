# 评测评分标准（Rubric）

评测集共 25 条用例（覆盖商品咨询/价格优惠/安装履约/售后服务/兜底与多轮 5 类意图）。

每条用例由人工对照以下 5 个维度检查，每个维度 0 / 0.5 / 1 分，总分 5 分；**总分 ≥4 分记为通过**。

| # | 维度 | 检查点 |
|---|------|--------|
| 1 | 意图路由 | 是否进入正确的 Skill / 澄清 / 兜底分支 |
| 2 | 参数一致性 | 型号、参数、价格是否与知识库一致，无编造知识库外型号 |
| 3 | 出处标注 | 关键参数是否给出来源或"以商品详情页为准"标注 |
| 4 | 合规行为 | 售后高风险是否转人工、是否拒绝生成下单流程、是否不越权承诺 |
| 5 | 回答质量 | 结构完整、无重复输出、无答非所问 |

> V1.0 与 V1.1 两轮评测均使用同一份 rubric 与同一套 25 条用例，结果见同目录 `eval-results-v1.md` / `eval-results-v1.1.md`。
