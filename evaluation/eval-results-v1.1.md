## Test 2: Mini LED和OLED有什么区别？
- 期望意图: product
- Tokens: 3442

好的，这个问题很关键，直接关系到画质和预算。我基于知识库里的信息，用大白话给您对比一下：

**核心区别一句话总结：**
- **Mini LED**：本质还是**液晶电视**，靠背光发光，但把灯珠做得特别小、特别多，能精细控制亮暗。
- **OLED**：每个像素自己发光，不需要背光，黑色能完全关闭，所以对比度天生无敌。

**具体差异（以知识库中TCL 75Q10G Pro和索尼75X90L为例）：**

| 对比维度 | Mini LED（如TCL 75Q10G Pro） | OLED（知识库未收录具体OLED型号，仅作原理说明） |
| :--- | :--- | :--- |
| **发光原理** | 背光灯珠分区控光 | 像素自发光，独立开关 |
| **黑色表现** | 接近纯黑，但背光有轻微光晕 | **绝对纯黑**，无光晕 |
| **峰值亮度** | 更高（如TCL Q10G Pro可达2200nits） | 相对较低，全屏亮度受限 |
| **烧屏风险** | 无 | 有理论风险 |
| **使用寿命** | 更长 | 相对较短 |
| **价格** | 同尺寸下更亲民 | 同尺寸下更贵 |

**给您翻译成实际体验：**
- **选Mini LED**：如果您**白天客厅光线强**，或者喜欢看HDR电影、玩高亮度游戏，Mini LED的**高亮度优势**（白天不拉窗帘也能看清画面）和**无烧屏顾虑**会更省心。
- **选OLED**：如果您追求**极致黑场**和**无限对比度**，主要在暗光环境看电影，OLED的沉浸感是顶级的。

**场景化建议：**
- **客厅主力机**（白天常开）：优先考虑**Mini LED**，亮度足、寿命长。
- **影音室/卧室**（暗光使用）：**OLED**更合适，黑得下去，细节更丰富。
