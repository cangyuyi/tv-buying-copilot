# 商品参数库

## 一、画质技术词条

### Mini LED
- 定义：以微型LED灯珠作为背光源的液晶显示技术，灯珠数量越多，控光分区越精细
- 用户感知：对比度高、亮度高（峰值亮度可达1000-3000nits）、HDR效果好、白天不拉窗帘也能看清
- 适合：客厅采光好、常看HDR电影/体育赛事、预算中等偏上
- 注意：Mini LED是液晶电视的背光升级，不是自发光

### OLED
- 定义：有机发光二极管，每个像素自发光，无需背光
- 用户感知：纯黑（像素级关闭）、对比度无限大、响应速度快（0.1ms）、可视角度大、超薄
- 适合：暗室观影、游戏玩家、追求极致画质
- 注意：峰值亮度不如Mini LED（亮室表现稍弱）；长期显示静态画面有烧屏风险（正常观看影响不大）；价格较高

### QLED（量子点）
- 定义：在液晶背光前加一层量子点薄膜，提升色域纯度
- 用户感知：色彩鲜艳、色域覆盖广（可达100% DCI-P3以上）、色彩持久不褪色
- 适合：对色彩要求高（动画、自然风光）、预算有限想要好色彩
- 注意：QLED本质仍是液晶，对比度取决于背光分区，不等于OLED

### ULED（海信专有）
- 定义：海信自研画质芯片+背光分区控制技术的统称
- 用户感知：通过算法优化提升对比度、运动补偿、色彩表现
- 注意：ULED是海信的营销+技术组合，不同型号配置差异大，需看具体分区数

### XR认知芯片（索尼专有）
- 定义：索尼自研画质处理芯片，通过AI分析画面内容进行实时优化
- 用户感知：动态范围、色彩、运动补偿综合表现优秀，处理器算法成熟
- 适合：追求稳定画质表现、PS5玩家（索尼电视游戏适配好）

### 峰值亮度（nits/尼特）
- 定义：屏幕最亮区域能达到的最大亮度
- 用户感知：500nits以下白天看偏暗；800-1000nits白天正常观看；1300nits以上HDR效果明显；2000nits+旗舰级
- 注意：看"峰值亮度"而非"典型亮度"，峰值是HDR小窗口亮度

### 刷新率（Hz）
- 60Hz：日常追剧够用，高速运动画面有拖影
- 120Hz：体育赛事、动作电影、游戏流畅；2024年后中高端标配
- 144Hz及以上：电竞级，配合HDMI 2.1效果最佳
- 注意：原生120Hz和"120Hz解码"不同，前者是面板原生支持

### MEMC运动补偿
- 定义：通过插帧算法将低帧率内容提升到高帧率显示
- 用户感知：看球赛、动作片画面更流畅，减少拖影
- 注意：部分低端机型的MEMC会产生画面伪影，中端以上表现较好

### 色域
- DCI-P3：好莱坞电影工业标准，90%以上为良好，95%以上为优秀
- BT.2020：超高清广播标准，覆盖范围更大，50%以上为良好
- 注意：色域不是越高越好，色彩准确性（色准ΔE<2）同样重要

### 色准（ΔE）
- 定义：显示颜色与标准颜色的偏差值，越小越准
- 用户感知：ΔE<2人眼几乎无法分辨色差；ΔE<3为专业级；ΔE>3可能偏色
- 注意：厂家宣传的ΔE值通常是最优值，实际表现看评测

### HDMI 2.1
- 定义：最新HDMI接口标准，带宽48Gbps（满血版）
- 用户感知：支持4K 120Hz、VRR（可变刷新率）、ALLM（自动低延迟），接PS5/Xbox/高端PC必备
- 注意：区分"满血48Gbps"和"残血24Gbps"；部分电视只有1个HDMI 2.1接口

### VRR / ALLM
- VRR（可变刷新率）：游戏画面不撕裂，帧率波动时同步刷新
- ALLM（自动低延迟模式）：检测到游戏信号自动进入游戏模式，输入延迟降至最低
- 适合：PS5、Xbox Series X/S、RTX 40系显卡用户

### 控光分区
- 定义：将背光分成多个独立区域，根据画面内容独立调节亮度
- 用户感知：分区越多，光晕越少，对比度越高
- 参考：百级分区为入门、三百级为中端、五百级以上为高端、千级以上为旗舰
- 注意：看"背光分区数"而非"像素分区"等营销概念

## 三、尺寸选择指南

### 观看距离与尺寸推荐

| 观看距离 | 推荐尺寸 | 说明 |
|---|---|---|
| 2.0-2.5米 | 55-65英寸 | 卧室/小客厅 |
| 2.5-3.0米 | 65-75英寸 | 主流客厅，75寸沉浸感明显 |
| 3.0-3.5米 | 75-85英寸 | 大客厅，75寸起步 |
| 3.5米以上 | 85-98英寸 | 别墅/大平层，需考虑入户 |

### 尺寸选择注意事项
1. 电视"买大不买小"，同距离下大尺寸沉浸感提升明显
2. 4K分辨率下，2.5米看75寸不会看到像素点
3. 大尺寸务必确认电梯/楼道/入户门能否进入（75寸包装约1800×1100×400mm）
4. 挂装需确认墙体承重（75寸约30-35kg，实心墙无压力，石膏板墙需加固）
5. 电视柜长度建议大于电视宽度（75寸宽约1.67米，电视柜建议1.8米以上）
