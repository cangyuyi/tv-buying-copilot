# 售后规则库

## 一、退换货政策

### 京东自营电视退换货标准

| 场景 | 期限 | 条件 | 处理方式 |
|---|---|---|---|
| 7天无理由退货 | 签收后7天内 | 商品完好、包装齐全、未安装挂装 | 全额退款 |
| 质量问题退货 | 签收后30天内 | 经检测确属性能故障 | 全额退款+退运费 |
| 质量问题换货 | 签收后30天内 | 经检测确属性能故障 | 免费换新 |
| 外观损/错发漏发 | 签收后48小时内 | 提供照片证据 | 免费换新/补发 |

### 不支持7天无理由退货的情况
- 已挂装安装且非质量问题（座装不影响）
- 包装损坏/缺失影响二次销售
- 人为损坏（摔碰、进水、自行拆机）
- 激活后不支持退货的智能产品（电视一般不涉及）

### 退换货流程
1. 订单页→"申请售后"→选择退货/换货
2. 上传问题照片/视频
3. 客服审核（一般24小时内）
4. 审核通过→预约上门取件（大家电免费上门取退）
5. 商品退回检测→退款/换货发出
6. 退款时效：检测通过后1-3个工作日原路退回

### 注意事项
- 挂装后的电视如非质量问题不支持7天无理由退货，建议先座装验机确认无问题再挂装
- 大促期间退换货审核可能延长至48小时
- 第三方店铺退换货以店铺政策为准，可能不支持上门取退

## 二、保修标准

### 京东自营电视保修政策

| 保修项 | 保修期限 | 说明 |
|---|---|---|
| 整机保修 | 1年 | 自签收之日起，非人为损坏免费维修 |
| 屏幕保修 | 3年 | 屏幕本身质量问题（非外力损坏）免费更换 |
| 主要部件保修 | 3年 | 主板、电源板、逻辑板等核心部件 |
| 遥控器/底座 | 1年 | 随机附件 |
| 京东安装质保 | 90天 | 京东安装导致的问题免费上门处理 |

### 保修流程
1. 联系京东客服或品牌售后（电话/APP/公众号）
2. 描述故障现象，提供订单号/照片
3. 远程指导无法解决→预约上门检测
4. 检测确认非人为损坏→免费维修/换件
5. 维修后同一故障90天内复发免费再次维修

### 不在保修范围
- 人为损坏（摔落、碰撞、进液、自行拆机）
- 不可抗力（雷击、电压异常等，部分可走保险）
- 非京东/品牌授权人员安装/维修导致的损坏
- 正常使用老化（遥控器电池等耗材）
- 屏幕划痕等外观磨损

## 五、人工转接规则

### 必须转人工的场景（P0）
- 用户明确要求转人工/投诉
- 退换货/退款/赔偿诉求
- 情绪激烈/辱骂/威胁投诉
- 涉及人身安全（电视起火/冒烟/漏电）
- 法律纠纷/媒体曝光风险

### 建议转人工的场景（P1）
- AI连续2轮无法解决问题
- 复杂售后（多次维修未解决）
- 价保/差价争议
- 订单异常（超时未发货/送错地址）
- 用户对AI回答表示不满/质疑

### 转人工话术
- P0场景："非常抱歉给您带来不好的体验，我马上为您转接人工客服处理，请稍候。"
- P1场景："这个问题我帮您转接人工客服可以更准确地处理，正在为您接通，请稍等。"
- 转人工时自动携带：对话记录摘要、用户意图、已确认信息，减少用户重复描述

### 转人工后
- 人工客服可查看完整AI对话记录
- 人工处理结果记录回系统，用于AI Bad Case分析
- 转接率作为AI效果核心指标持续优化
